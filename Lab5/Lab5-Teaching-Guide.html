00The task

  • A simple JavaFX application with Name, Age, Email and a Submit button.
  • On Submit, a pop-up shows the details entered.
  • Validate the input as much as possible.
  • Follow the Model View Controller (MVC) architecture.

01Install the tools

Do this once per computer. Tick each item off as you go.

Why download JavaFX separately?Since Java 11, JavaFX isn't part of the JDK. You give Java its location in two places: when compiling (Libraries) and when running (VM Options). Step 08 covers both.

02What MVC means

MVC splits the app into three jobs, and each job lives in its own package. No part does another part's job.

Model model/User.java
model/UserValidator.java

The data and the rules. It knows nothing about windows or buttons, so it can be tested on its own.

View view/UserForm.fxml
view/style.css

What the screen looks like. You build it in Scene Builder. It contains no logic.

Controller controller/UserFormController.java

The go-between. It reacts to clicks, reads the View, asks the Model, and updates the View.

What happens when you click Submit

  1. The button in the FXML has onAction="#handleSubmit", so JavaFX calls handleSubmit() in the Controller.
  2. The Controller reads the three text fields. They are linked because each @FXML field name matches an fx:id in the FXML.
  3. The Controller asks UserValidator (Model) whether each value is valid.
  4. If something is wrong, the field turns red, its message appears under it, and an error pop-up lists every problem.
  5. If everything is valid, the Controller creates a User (Model) and shows its details in an Alert pop-up. The form then clears.

  1. File › New Project › Java with Ant › Java Application. Click Next.
  2. Name it Lab5, untick "Create Main Class", and click Finish.
  3. Right-click Source Packages › New › Java Package and create four packages: model, view, controller, app.
Package names matterEach Java file starts with package model; (or view, controller, app). It must match the folder the file is in, otherwise NetBeans shows a red error on the first line.

04Write the Model

Start with the Model because it has no dependencies. Right-click model › New › Java Class for each file.

User is a plain class that carries the three values. UserValidator holds the rules. Each method returns an error message, or null when the value is fine. Keeping the rules here and not in the Controller is what makes the design true MVC.

User.java src/model/
User.java
package model;

/**
 * MODEL: holds the data for one user.
 * It knows nothing about JavaFX, buttons or text fields.
 */
public class User {

    private final String name;
    private final int age;
    private final String email;

    public User(String name, int age, String email) {
        this.name = name;
        this.age = age;
        this.email = email;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    public String getEmail() {
        return email;
    }

    @Override
    public String toString() {
        return "Name:  " + name + "\n"
             + "Age:   " + age + "\n"
             + "Email: " + email;
    }
}
UserValidator.java src/model/

The rules: Name 2–50 letters (spaces, hyphens, apostrophes and dots allowed); Age a whole number from 1 to 120; Email in the form name@domain.com with no spaces or "..".

UserValidator.java
package model;

import java.util.regex.Pattern;

/**
 * MODEL: the business rules for what counts as valid input.
 * Each method returns an error message, or null when the value is valid.
 * Keeping the rules here (not in the controller) means they can be
 * reused or tested without any user interface.
 */
public class UserValidator {

    // Letters (any language), spaces, apostrophes, hyphens and dots, e.g. "Mary-Jane O'Neil Jr."
    private static final Pattern NAME_PATTERN = Pattern.compile("^[\\p{L}][\\p{L} .'-]*$");

    // something@domain.tld, no spaces, at least one dot in the domain, 2+ letter ending
    private static final Pattern EMAIL_PATTERN =
            Pattern.compile("^[A-Za-z0-9._%+-]+@[A-Za-z0-9-]+(\\.[A-Za-z0-9-]+)*\\.[A-Za-z]{2,}$");

    public static final int MIN_AGE = 1;
    public static final int MAX_AGE = 120;

    public static String validateName(String name) {
        if (name == null || name.isBlank()) {
            return "Name is required.";
        }
        String trimmed = name.trim();
        if (trimmed.length() < 2) {
            return "Name must be at least 2 characters.";
        }
        if (trimmed.length() > 50) {
            return "Name must be at most 50 characters.";
        }
        if (!NAME_PATTERN.matcher(trimmed).matches()) {
            return "Name can only contain letters, spaces, apostrophes, hyphens and dots.";
        }
        return null;
    }

    public static String validateAge(String ageText) {
        if (ageText == null || ageText.isBlank()) {
            return "Age is required.";
        }
        String trimmed = ageText.trim();
        if (!trimmed.matches("\\d+")) {
            return "Age must be a whole number (digits only).";
        }
        int age;
        try {
            age = Integer.parseInt(trimmed);
        } catch (NumberFormatException e) {
            return "Age is too large.";
        }
        if (age < MIN_AGE || age > MAX_AGE) {
            return "Age must be between " + MIN_AGE + " and " + MAX_AGE + ".";
        }
        return null;
    }

    public static String validateEmail(String email) {
        if (email == null || email.isBlank()) {
            return "Email is required.";
        }
        String trimmed = email.trim();
        if (trimmed.length() > 254) {
            return "Email is too long.";
        }
        if (trimmed.contains("..")) {
            return "Email cannot contain two dots in a row.";
        }
        if (!EMAIL_PATTERN.matcher(trimmed).matches()) {
            return "Enter a valid email, e.g. name@example.com.";
        }
        return null;
    }
}

05Design the View

  1. Right-click view › New › Other › JavaFX › Empty FXML and name it UserForm.
  2. Right-click UserForm.fxml › Open. It opens in Scene Builder.
  3. Drag in a VBox, then a Label for the title, a GridPane with Labels and TextFields for Name, Age and Email, a small error Label under each field, and an HBox holding Clear and Submit buttons.
  4. Select each TextField. In the Code panel on the right, set its fx:id: nameField, ageField, emailField. Name the error labels nameError, ageError, emailError.
  5. Select Submit and set On Action to handleSubmit. Set Clear's to handleClear.
  6. In the left Controller panel, set the controller class to controller.UserFormController. Save.

06Write the Controller

Points to explain while writing this file:

  • @FXML fields are filled in automatically. Their names must match the fx:id values exactly.
  • initialize() runs once after loading. It sets up live re-checking and stops letters from being typed into Age.
  • validateName() & validateAge() & validateEmail() uses a single & so all three checks run and every error shows at once. With &&, Java would stop at the first failure.
  • showAndWait() pauses until the pop-up is closed, so handleClear() runs only after the user clicks OK.
UserFormController.java src/controller/
UserFormController.java
package controller;

import javafx.fxml.FXML;
import javafx.scene.control.Alert;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;
import model.User;
import model.UserValidator;

/**
 * CONTROLLER: the middleman between the View (UserForm.fxml) and the Model.
 * 1. Reads what the user typed from the View.
 * 2. Asks the Model (UserValidator) whether it is valid.
 * 3. Either shows the errors, or builds a User and shows it in a pop-up.
 */
public class UserFormController {

    // Each @FXML field matches an fx:id in UserForm.fxml; FXMLLoader fills them in.
    @FXML private TextField nameField;
    @FXML private TextField ageField;
    @FXML private TextField emailField;
    @FXML private Label nameError;
    @FXML private Label ageError;
    @FXML private Label emailError;

    /** Called automatically by FXMLLoader after the @FXML fields are set. */
    @FXML
    private void initialize() {
        // Live validation: re-check a field every time its text changes,
        // but only after the user has already seen an error for it.
        nameField.textProperty().addListener((obs, oldV, newV) -> {
            if (!nameError.getText().isEmpty()) validateName();
        });
        ageField.textProperty().addListener((obs, oldV, newV) -> {
            if (!ageError.getText().isEmpty()) validateAge();
        });
        emailField.textProperty().addListener((obs, oldV, newV) -> {
            if (!emailError.getText().isEmpty()) validateEmail();
        });

        // Block anything other than digits being typed into Age (max 3 digits).
        ageField.setTextFormatter(new javafx.scene.control.TextFormatter<String>(change ->
                change.getControlNewText().matches("\\d{0,3}") ? change : null));
    }

    /** Runs when Submit is clicked (onAction="#handleSubmit" in the FXML). */
    @FXML
    private void handleSubmit() {
        // Use & (not &&) so every field is checked and every error is shown at once.
        boolean valid = validateName() & validateAge() & validateEmail();

        if (!valid) {
            showAlert(Alert.AlertType.ERROR, "Invalid Input",
                    "Please fix the highlighted fields.", collectErrors());
            return;
        }

        User user = new User(
                nameField.getText().trim(),
                Integer.parseInt(ageField.getText().trim()),
                emailField.getText().trim());

        showAlert(Alert.AlertType.INFORMATION, "Details Submitted",
                "Thank you! Here are the details you entered:", user.toString());

        // showAndWait() above blocks until the pop-up is closed, then the form is reset.
        handleClear();
    }

    /** Runs when Clear is clicked. */
    @FXML
    private void handleClear() {
        nameField.clear();
        ageField.clear();
        emailField.clear();
        setError(nameField, nameError, null);
        setError(ageField, ageError, null);
        setError(emailField, emailError, null);
        nameField.requestFocus();
    }

    private boolean validateName() {
        return setError(nameField, nameError, UserValidator.validateName(nameField.getText()));
    }

    private boolean validateAge() {
        return setError(ageField, ageError, UserValidator.validateAge(ageField.getText()));
    }

    private boolean validateEmail() {
        return setError(emailField, emailError, UserValidator.validateEmail(emailField.getText()));
    }

    /** Shows or hides the error under a field and the red border. Returns true when valid. */
    private boolean setError(TextField field, Label errorLabel, String message) {
        if (message == null) {
            errorLabel.setText("");
            field.getStyleClass().remove("invalid");
            return true;
        }
        errorLabel.setText(message);
        if (!field.getStyleClass().contains("invalid")) {
            field.getStyleClass().add("invalid");
        }
        return false;
    }

    private String collectErrors() {
        StringBuilder sb = new StringBuilder();
        for (Label l : new Label[] {nameError, ageError, emailError}) {
            if (!l.getText().isEmpty()) {
                sb.append("\u2022 ").append(l.getText()).append("\n");
            }
        }
        return sb.toString().trim();
    }

    private void showAlert(Alert.AlertType type, String title, String header, String content) {
        Alert alert = new Alert(type);
        alert.setTitle(title);
        alert.setHeaderText(header);
        alert.setContentText(content);
        alert.showAndWait();
    }
}

07Start the app

Main extends Application. Its only job is to load the FXML and show the window. When FXMLLoader reads fx:controller, it creates the Controller and connects it to the View.

Main.java src/app/
Main.java
package app;

import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.stage.Stage;

/**
 * Entry point. Loads the View (FXML); FXMLLoader creates the Controller
 * named in fx:controller and connects them.
 */
public class Main extends Application {

    @Override
    public void start(Stage stage) throws Exception {
        Parent root = FXMLLoader.load(getClass().getResource("/view/UserForm.fxml"));
        stage.setTitle("Lab 5 - User Registration (MVC)");
        stage.setScene(new Scene(root));
        stage.setResizable(false);
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
The leading slash"/view/UserForm.fxml" means "start from the top of src". Without the slash, Java looks inside the app package and returns null.

08Configure and run

Right-click the project and choose Properties.

  1. Libraries › Classpath › + › Add JAR/Folder. Select every .jar in the JavaFX SDK's lib folder. (Or create a reusable library once in Tools › Libraries › New Library and add that.)
  2. Run › Main Class: app.Main
  3. Run › VM Options: paste this line and change the path to your own lib folder:
VM Options
--module-path "C:\Users\<you>\Java\openjfx-27_windows-x64_bin-sdk\javafx-sdk-27\lib" --add-modules javafx.controls,javafx.fxml --enable-native-access=javafx.graphics
